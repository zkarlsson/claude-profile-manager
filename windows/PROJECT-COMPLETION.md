## 🚫 **Design Decisions: Excluded Features**

### **Windows Registry Integration** - Intentionally Excluded
- **Reason**: Adds unnecessary complexity without user value
- **Current Solution**: Per-user configuration works optimally
- **Benefits**: Simpler deployment, better security, enterprise compatibility

### **Windows Service Wrapper** - Intentionally Excluded  
- **Reason**: No background operations needed for profile management
- **Current Solution**: On-demand execution when users need it
- **Benefits**: Lower resource usage, simplified troubleshooting, better security

*These exclusions follow software engineering best practices: KISS principle, minimal attack surface, and user-centric design.*
